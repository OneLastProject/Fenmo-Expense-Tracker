### Key Design Decisions
- **React Context API for State:** Used Context API for global state to keep things simple and avoid Redux overhead for a small app.
- **Component-Based Structure:** Broke features into focused, reusable components for clarity and maintainability.
- **Vanilla CSS:** Opted for basic CSS to save time and keep the UI clean, skipping frameworks like Material UI or Bootstrap.

### Trade-offs Due to Timebox
- **Basic Validation:** Form validation is minimal.
- **Simple Filtering:** Filtering is straightforward and based on exact matching.

### Intentional Omissions
- **Authentication:** No user login or authentication to keep the project focused on core features.
- **Automated Testing:** Did not include automated tests due to time constraints.
